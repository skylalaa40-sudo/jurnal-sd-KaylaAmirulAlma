# Mid-Term Reflection

Selama mempelajari materi dari Minggu 1 sampai Minggu 7, saya mengalami beberapa kesulitan terutama pada penggunaan Git seperti branching dan merging. Awalnya saya sering bingung ketika berpindah branch dan saat terjadi konflik pada file.
Selain itu, saya juga sempat kesulitan memahami konsep MVC karena harus memisahkan bagian model, view, dan controller dengan benar agar sistem tetap rapi.
Untuk mengatasi hal tersebut, saya melakukan latihan langsung menggunakan repository, membaca dokumentasi Git, serta mencoba melakukan commit kecil secara bertahap agar lebih mudah melacak perubahan.

Dari proses tersebut, saya memahami bahwa Git dan MVC sangat penting dalam pengembangan perangkat lunak karena membantu menjaga keteraturan dan kerja sama dalam tim.
