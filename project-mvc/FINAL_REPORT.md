# Deskripsi Proyek
Proyek ini merupakan implementasi aplikasi berbasis arsitektur MVC yang dikembangkan secara kolaboratif menggunakan Git, GitHub, Docker, Docker Compose, dan GitHub Container Registry (GHCR).


# Kontribusi Saya Sebagai Frontend Developer

Selama 16 minggu pengembangan proyek, saya bertanggung jawab pada implementasi dan integrasi antarmuka pengguna (Frontend).

Kontribusi yang telah saya kerjakan antara lain:
- Membuat struktur folder frontend sesuai pola MVC.
- Mendesain dan mengembangkan tampilan Landing Page.
- Mendesain Dashboard aplikasi.
- Membuat komponen UI sesuai dokumen Mockup.
- Menyusun dokumentasi UI Components.
- Mengintegrasikan frontend dengan backend menggunakan Fetch API.
- Menangani kondisi Loading, Success, dan Error pada tampilan aplikasi.
- Menambahkan konfigurasi environment variable untuk frontend.
- Mengimplementasikan Docker dan Docker Compose.
- Menggunakan Bind Mount pada Docker.
- Membuat Production Image menggunakan Multi-stage Docker Build.
- Melakukan Push image ke GitHub Container Registry (GHCR).
- Melakukan simulasi Deployment dan Rolling Update menggunakan Docker.
- Membuat halaman browser sederhana menggunakan Flask sebagai simulasi aplikasi produksi.
